# Reference Examples

Documents describing a specific hardware setup do not belong in the
project: they hold one installation's serials, UUIDs and layout. Keep
your own as gitignored `local-*.md` files in this directory.

Use `docs/DAS-BAY-MAPPING.md` as the template for a bay map and
`docs/STORAGE-ARCHITECTURE-AND-RECOVERY.md` for the storage layout concepts.
